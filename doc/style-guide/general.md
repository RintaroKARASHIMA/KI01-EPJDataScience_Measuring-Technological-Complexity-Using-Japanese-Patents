# 修正方針(全体)

`sn-article.tex` を編集・翻訳する際に共通して守る方針。個別の論点に対する方針は同じ `doc/style-guide/` 配下に別ファイルとして追加する。

## 英語のトーン

- フォーマルな学術英語(Springer/EPJ 標準)を基本とする。口語的な短縮形(don't 等)は使わない
- 受動態を含む標準的な学術表現は許容するが、簡潔さを優先し不要な冗長表現は避ける
- ダッシュ・コロン・セミコロン・過剰な分詞構文・倒置は使わない
- カンマ・ピリオドは省略せず正確につける
- "Overall" のような文語的な繋ぎ表現は避け、computer science 系学術誌の原著論文で一般的な表現を使う
- 語彙・語法は TOEIC 700〜800点台程度を目安にする(平易だが学術的に不自然でない範囲)
- 迷ったら `sn-article.tex` の既存箇所のトーンに合わせる

## 修正・翻訳の方針

- 本文の fix はオリジナルの文意・構成を尊重し、上記トーンの制約を守った上で最小限の変更にとどめる
- 読解・翻訳の際は語句の意味を尊重し、コンテキストに応じて意味の損失・追加が起きないように訳す
