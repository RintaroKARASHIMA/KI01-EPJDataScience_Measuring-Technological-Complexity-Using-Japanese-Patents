
# EPJ Data Science — Submission Guidelines 要約

> **第1部: 一般ガイドライン**

出典: https://link.springer.com/journal/13688/submission-guidelines (2026-09-17 取得)
構成: 第1部 = 一般ガイドライン(上記URL)、第2部 = 記事種別ごとのガイドライン(Regular Article / Brief Report / Review / Database / Commentaries、各記事種別ページより)。

## 1. 投稿前に確認すること

- **Aims and scope** — 投稿先として適切か
- **Fees and funding** — APC と資金オプション
- **Licensing and copyright** — ライセンス形態

投稿は著者本人のみ可能(第三者による代理投稿は不可)。

## 2. Aims and scope

- データ駆動型科学の立場から、人間活動の「デジタルトレース」とそこから学習したモデルを一次的な研究対象として扱う techno-socio-economic systems の研究を掲載
- 対象領域(例): 社会的相互作用(動物社会含む)、経済・金融、経営・ビジネスネットワーク、社会技術インフラ、健康・環境、科学の科学(science of science)、生成言語モデル、リスク・危機予測〜政策助言
- 手法: 統計的に厳密なデータ分析、社会ネットワーク分析、複雑系、応用機械学習など、分野横断を歓迎
- **必須条件**: 手法改善だけでなく、人間・社会の行動やシステムについて**新しい知見**を提示すること
- **不採択になりやすいもの**: 記述統計のみ、標準手法を既知データセットに適用しただけの研究

## 3. Fees and funding

- 完全 OA 誌。採択論文ごとに **APC** が発生(採択日時点の価格が適用)
- 現在の APC: **£1,340 / $1,990 / €1,690**(別途 VAT・地方税)
- 機関の OA 契約、研究資金提供者からの補助で賄える場合あり
- 低所得国の corresponding author は免除・割引制度あり。それ以外は個別審査
- **免除・割引申請は投稿時に行う**(査読中・採択後は不可)

## 4. Licensing and copyright

- 著作権は著者に帰属(Creative Commons)
- 選択可: **CC BY-NC-ND 4.0**(非商用・改変不可)または **CC BY 4.0**(商用含め再利用・改変可、要クレジット)
- 資金提供者の要件に合わせたライセンス変種も相談可

## 5. Prepare your manuscript(原稿の書式)

### 5.1 本文

**基本ルール**

- ダブルスペース
- 行番号・ページ番号を入れる
- SI 単位を使用。特殊文字は埋め込む(PDF 変換で消失するため)
- ページ区切り(page break)は使わない

**ファイル形式(本文)**

- Word (DOC/DOCX)、RTF、TeX/LaTeX
- 編集可能ファイルが必須。PDF のみで出した場合、改訂時または採択後に編集可能ファイルの再提出が求められる

**LaTeX ユーザー向け**

- Springer Nature の LaTeX テンプレート使用を推奨
- 投稿時に pdfLaTeX + TeX Live 2021 でコンパイルされる
- 関連するソースファイルはすべてアップロード(欠けると製作工程で遅延)

### 5.2 データ・資料

- 結論の根拠となるデータセットは公開リポジトリへの寄託、または本文/追加ファイルでの提供を強く推奨(記事種別により必須)
- 機械可読形式で提供(PDF ではなくスプレッドシート等)
- 研究コミュニティで公開リポジトリへのアーカイブが慣行となっている分野では、コミュニティ推奨リポジトリへの寄託が**必須**
- 全原稿に **"Availability of data and materials"** セクションが必要

**同セクションの定型文**

- リポジトリの場合: データセットが [リポジトリ名] で利用可能である旨と、永続識別子・https リンクを記載
- 追加ファイルに含める場合: データセットが本記事(および追加ファイル)に含まれている旨を記載
- 公開データセットは DOI 等の識別子付きで参考文献リストに載せる(Force 11 Data Citation Principles 準拠)
- **データベース**の場合: URL と非学術利用の制限を記載
- **ソフトウェア**の場合: プロジェクト名 / ホームページ / アーカイブ版の DOI(例: Zenodo)/ OS / 言語 / その他要件 / ライセンス / 非学術利用の制限

### 5.3 参考文献

**引用できるもの**

- 出版済み・in press・公開プレプリントサーバーにある論文、臨床試験登録、抄録
- 未出版の抄録・データ・私信は参考文献リストには入れず、本文中で "unpublished observations" / "personal communications" として研究者名を挙げる(許諾取得は著者責任)
- 脚注のみ許可。雑誌略称は Index Medicus/MEDLINE 準拠
- 査読に必要な in press 論文は求められれば提出

**Web リンク・URL**

- 本文中ではなく参考文献リストに番号付きで記載
- サイト名・URL・アクセス日をすべて記載
- 著者が特定できる場合(ブログ等)は著者名も記載

### 5.4 図(Figures)

**基本**

- 本文での初出順に番号付け・同じ順でアップロード
- 複数パネル(a, b, c…)は 1 つの複合ファイルに
- 正しい向きでアップロード
- タイトル(**15 語以内**)と凡例(**300 語以内**)は本文側に書く(画像ファイルには入れない)
- 図中のキー(legend key)は画像側に入れる
- 余白を最小化するようトリミング
- 1 ファイル **10 MB 以下**
- 他誌掲載済みの図表は著者が許諾を取得。凡例に許諾を明記し、原典を参考文献に入れる

**ファイル形式**

- EPS / PDF(図・画像)、Word / PowerPoint(1 ページ限定)、TIFF / PNG / BMP(画像)、JPEG(写真向き)、CDX(分子構造)

**サイズ・解像度**

- Web: 幅 600px(標準)/ 1200px(高解像度)
- PDF: 半幅 **85 mm**、全幅 **170 mm**、図+凡例の高さ最大 **225 mm**、最終サイズで約 **300 dpi**
- 上記サイズで文字が読めること。線幅 0.25 pt 超。フォント埋め込み必須

**圧縮**

- ベクター図は PDF 推奨(EPS より軽い)
- TIFF は LZW(可逆)圧縮
- JPEG は最高品質で保存。形式変換は最小限に

### 5.5 表(Tables)

- アラビア数字で番号付け、本文で順に引用(Table 1, 2…)
- A4/Letter 1 ページ以内 → 本文の該当箇所に配置
- 1 ページ超 → 本文末尾に置き、挿入位置を本文中に示す
- さらに大きい・横長のもの → 追加ファイル(.xls / .csv)
- タイトル(**15 語以内**)は表の上、凡例(**300 語以内**)は表の下
- 画像やスプレッドシートの埋め込みではなく、ワープロの「表」オブジェクトで作成
- **色・網掛け不可**。強調は上付き・番号・記号・太字で行い、意味を凡例で説明
- 数値にカンマ区切りを使わない

### 5.6 追加ファイル(Additional files)

- データセット・表・動画等を追加ファイルとして提出可。採択論文と一緒に公開される
- 含めないもの: 同意書、英文校正証明書、変更履歴付き改訂原稿(求められた場合はメールで)
- "data not shown" としたくなる結果は追加ファイルに含める
- 個人サイト・部局サイトへのリンクは不可(リンク切れ防止のため、追加ファイルまたはリポジトリへ)
- 参加者個人の詳細は含めない
- 1 ファイル **20 MB 以下**。本文中で順に引用
- 原稿内に専用セクションを設け、各ファイルについて **ファイル名(例: Additional file 1)/ 形式・拡張子 / タイトル / 説明** を記載
- 本文中では "see Additional file 1" のようにファイル名で明示的に参照

## 6. Language editing

- 明瞭な英語で書くことが推奨。ネイティブ同僚のレビューや校正サービスの利用は任意
- Springer Nature Author Services(初回 15% 割引)、AJE の無料 AI 言語チェックあり
- これらの利用は採択を保証しない

## 7. Prepare supporting information(投稿時に用意するもの)

**著者情報**: 全共著者のフルネームとメールアドレス

**カバーレター**に含める内容

- なぜ EPJ Data Science に掲載すべきか
- ジャーナル方針に関わる事項の説明
- 競合利益の申告
- 全著者が投稿を承認していることの確認
- 他誌に未発表・未投稿であることの確認(二重投稿方針)
- 特集号(special issue)への投稿なら、その名称を明記

**査読者の提案**(任意)

- 機関メールアドレス、または ORCID / Scopus ID など本人確認に使える情報を添える
- 虚偽の査読者情報は不採択+不正行為調査の対象
- 査読を避けたい人物も記載可

## 8. Editorial policies

Springer Open の編集方針(全文)は別ページを参照。

## 9. Peer review policy

- 通常 2 名以上の専門家が評価。主な基準は 3 点:
  - **scientific robustness**(方法論の妥当性、データが結論を支持しているか)
  - **originality**(既発表研究の重複でないか)
  - **clarity**(明瞭で一貫しているか)
- **Single-anonymous**(査読者は著者名・所属を知る。著者には査読者名を伏せる)
- 特集号・コレクションへの投稿も同一の方針・プロセスで審査
- 査読者・編集者は競合利益を申告し、該当すれば除外

## 10. Manuscript transfers

- 不採択の場合、Springer Nature 内の他誌への移管(transfer)を提案されることがある
- 流れ: 不採択 → 代替誌の提示 → 移管 → 新誌で審査
- 利点: 選択肢の提示、再フォーマット不要
- **Transfer Desk** が著者の希望・編集者推薦・マッチング技術で候補誌を提案
- 著者の同意なしに移管されることはない。決定通知内のリンクで辞退可、放置でもクローズ
- 途中撤回も可。問い合わせ: transferdesk@springer.com

## 11. Promote your publication

- 出版社側でメール、SNS、ブログ、プレスリリース、学会等で宣伝
- 著者自身による SNS・メーリングリスト・学会配布・所属機関の広報経由での周知も推奨

## 13. 全種別共通の原稿構成

### 13.1 タイトルページ

- タイトル(適宜、研究デザインや記事内容の説明を含める)
- 全著者のフルネームと所属住所(Database は email も)
- 共同研究グループを著者とする場合はグループ名を著者に、個々のメンバー名は Acknowledgements に記載
- **LLM(ChatGPT 等)は著者になれない**(責任を負えないため)。LLM の使用は Methods 節(なければ適切な箇所)に記載
- corresponding author を明示

### 13.2 抄録・キーワード

- 抄録に未定義の略語・特定されない参照を含めない
- キーワード **3〜10 語**

### 13.3 本文・略語

- 本文は短く情報量のある見出しで小節に分けてよい
- Review / Commentaries は **Introduction**(背景・目的・文献調査の要約・論点)→ **Main text** → **Conclusions**(主な結論と分野への意義)
- 略語は初出時に本文で定義し、**略語一覧(List of abbreviations)** を付ける

### 13.4 脚注

- 本文中に上付き数字で指定
- **脚注を参考文献・引用の代わりに使うことは不可**

## 14. Declarations(全種別必須)

'Declarations' の見出しの下に以下の小節を**すべて**置く。該当しない項目も見出しは残し 'Not applicable' と書く。

| 小節                                         | 内容                                                                                                                                                                                          |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Availability of data and materials** | データの所在(公開アーカイブへのリンク含む)。「データ」= 結果の解釈・再現・発展に必要な最小データセット。非公開の場合もその旨と入手条件を記載                                                  |
| **Competing interests**                | 金銭的・非金銭的な競合利益を著者イニシャルで記載。なければ "The authors declare that they have no competing interests"                                                                        |
| **Funding**                            | 全資金源。資金提供者が研究設計・データ収集・分析・出版判断・執筆に関与した場合はその役割も                                                                                                    |
| **Authors' contributions**             | 各著者の貢献をイニシャルで記載。末尾に全著者が最終稿を読み承認した旨                                                                                                                          |
| **Acknowledgements**                   | 著者基準を満たさない貢献者(執筆支援・資料提供者含む)。記載相手の許諾を得る。なければ 'Not applicable'。グループ著者のメンバー名は最終段落に "First Name, Middle initial(s), Last Name" 形式で |
| **Authors' information**(任意)         | 読者の解釈を助ける著者の資格・現職など(イニシャルで)。競合利益の記載には使わない                                                                                                              |

### 14.1 Data availability statement の定型パターン(選択・組合せ可)

1. [リポジトリ名] で公開 + 永続リンク
2. corresponding author に合理的要請があれば提供
3. 本論文(および補足ファイル)に全データを含む
4. [理由] により非公開だが corresponding author に要請があれば提供
5. データセットを生成・分析していないため該当なし
6. [第三者名] からライセンス取得して使用したため非公開。著者への要請と第三者の許可があれば提供
7. データを含まない原稿は 'Not applicable'

- 結論の根拠となる公開データは本文中で引用し、**DOI 等の永続識別子を完全な URL で**参考文献リストに載せる(DataCite の最小情報に準拠)
- Statement 末尾に該当する参考文献番号を付ける
- データを説明する Data note を *BMC Research Notes* に同時投稿することも可

## 15. 参考文献スタイル(Basic Springer style)

形式の要点: `著者 (年) タイトル. 誌名 巻:ページ. doi:...` / 書籍は `著者 (年) 書名. 出版社, 都市.`

主な例(ページ掲載のダミー例より形式のみ抜粋):

| 種別                           | 形式                                                                                                                                                                                            |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 雑誌論文                       | `Smith J, Jones M Jr, Houghton L (1999) Future of health insurance. N Engl J Med 965:325-329.`                                                                                                |
| DOI 付き論文                   | `... J Mol Med 78:74-80. doi:10.1007/s001090000086.`                                                                                                                                          |
| 巻号未確定(DOI のみ)           | `... J Mol Med. doi:10.1007/s001090000086.`                                                                                                                                                   |
| 書籍の章                       | `Brown B, Aaron M (2001) The politics of nature. In: Smith J (ed) The rise of modern genomics, 3rd edn. Wiley, New York.`                                                                     |
| 単著書籍                       | `South J, Blass B (2001) The future of modern genomics. Blackwell, London.`                                                                                                                   |
| 編著書籍                       | `Smith J, Brown B (eds) (2001) The demise of modern genomics. Blackwell, London.`                                                                                                             |
| シリーズ内の章(巻タイトルあり) | `Smith SE (1976) ... In: Zaimis E (ed) Neuromuscular junction. Handbook of experimental pharmacology, vol 42. Springer, Heidelberg, pp 593-660.`                                              |
| 会議録(書籍形式)               | `Zowghi D (1996) ... In: Foo N, Goebel R (eds) PRICAI'96: ... Lecture notes in computer science, vol 1114. Springer, Heidelberg, p 157.`                                                      |
| 会議発表                       | `Chung S-T, Morris RL (1978) ... Paper presented at the 3rd international symposium ..., University of Wisconsin, Madison, 4-9 June 1978.`                                                    |
| 特許                           | `Norman LO (1998) Lightning rods. US Patent 4,379,752, 9 Sept 1998.`                                                                                                                          |
| 学位論文                       | `Trent JW (1975) Experimental acute renal failure. Dissertation, University of California.`                                                                                                   |
| 機関著者                       | `International Anatomical Nomenclature Committee (1966) Nomina anatomica. Excerpta Medica, Amsterdam.`                                                                                        |
| In press                       | `Major M (2007) Recent developments. In: Jones W (ed) Surgery today. Springer, Dordrecht (in press).`                                                                                         |
| Web / オンライン資料           | `著者 (年) タイトル. URL. Accessed 日 月 年.`                                                                                                                                                 |
| データセット                   | `Hao Z, AghaKouchak A, Nakhjiri N, Farahmand A. Global integrated drought monitoring and prediction system (GIDMaPS) data sets. figshare. 2014. http://dx.doi.org/10.6084/m9.figshare.853801` |

- 著者名はイニシャル、ピリオドなし(`Smith J`)

## 16. Database 記事の詳細(専用ルール)

**必須ステップ**

1. データをリポジトリに寄託(投稿要件)
2. 提供される **Database テンプレート**を使用。Table 1(ファイル形式・識別子・ライセンス)を埋める
3. 投稿。**補足ファイルは不可** — 追加データファイルとしてリポジトリ側に置く

**節構成と語数**

| 節                                   | 内容                                                                                                                                                                                                                                                                                                    | 語数     |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| Abstract                             | Objective(なぜ収集したか、副産物なら明記、将来どんな研究を可能にするか)+ Data description(他研究者にとっての有用性を強調)                                                                                                                                                                               | 約 300   |
| Objective                            | 収集の動機、答え得る研究課題、背景と文献、関連論文(同じ/旧版データに基づくもの)の引用、インパクトと用途                                                                                                                                                                                                 | 約 500   |
| Data Description                     | データセット一覧と説明、収集・処理の方法(倫理面含む)、記述統計と質的データの例、処理ステップ、**FAIR 原則への対応**、Datasheets for Datasets の観点、**検証**(手動ラベリング・他データとの比較等。検証スクリプトをリポジトリに含め、その実行結果として提示)、誤差・バイアス・不完全性の明記 | 約 1,000 |
| Limitations                          | データの限界(収集時の問題、小標本、古さなど)。箇条書き可。限界の正直な記述は掲載を妨げない                                                                                                                                                                                                              | 200 以内 |
| Data citations                       | データレコードを参考文献リストに入れ、Table 1 最終列と Availability statement にも引用                                                                                                                                                                                                                  | —       |
| List of abbreviations / Declarations | 共通                                                                                                                                                                                                                                                                                                    | 語数外   |

- 非専門家にも読めるように書く。略語・専門用語は最小限
- 共通の研究プロジェクト・サンプル・被験者に紐づく複数データセットは 1 記事で扱ってよい
- 再現に十分な詳細な方法論はリポジトリ側にアップロード
